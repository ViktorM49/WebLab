Демонстрація роботи з текстом в HTML

Жирний текст використовується для виділення важливих слів у реченні.

Важливий текст відображається подібно до жирного, але також позначає семантичне значення.

Курсивний текст використовується для позначення іншого стилю мовлення, наприклад, думок чи цитат.

Емфатичний текст означає, що слова потрібно підкреслити інтонаційно.

Текст меншого розміру часто використовується для додаткових пояснень або приміток.

H2O — хімічна формула води з використанням <sub>.

Ейнштейнів відомий вираз: E = mc2 — демонстрація <sup>.

У цьому реченні вставлено новий текст, який виділяється підкресленням.

Цей текст видалено як застарілий або непотрібний.

Ось виділений текст, який потребує уваги користувача.

Скорочення: HTML є основою веб-розмітки.

Цей текст буде зчитуватись справа наліво.

HTML надає багато тегів для семантичного виділення частин тексту.

Згідно з HTML Living Standard, потрібно використовувати теги відповідно до їх значення.
